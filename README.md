# Task 2: Exploratory Data Analysis (EDA)

## Objective

Understand the dataset structure, identify trends, detect anomalies, and prepare the data for further analysis.

## Activities Performed

### Data Exploration

* Loaded the dataset using Pandas.
* Examined rows and columns.
* Reviewed data types.
* Investigated dataset structure.

### Data Quality Checks

* Checked for missing values.
* Checked for duplicate records.
* Verified data consistency.

### Analysis Questions

The following questions were explored:

1. How many books are present in the dataset?
2. What information is available for each book?
3. Are there missing values?
4. Are there duplicate records?
5. What rating categories exist?
6. Is the price column suitable for numerical analysis?

### Key Findings

* Dataset contains 20 books.
* No missing values were detected.
* No duplicate records were found.
* Ratings range from One to Five stars.
* The Price column required cleaning because it contained currency symbols.

### Skills Gained

* Data exploration
* Data cleaning
* Data quality assessment
* Trend identification
* Statistical thinking

## Outcome

Successfully analyzed the dataset structure and identified preprocessing requirements for advanced analysis.

# Task 3: Data Visualization

## Objective

Transform raw data into meaningful visual representations that reveal patterns and support decision-making.

## Activities Performed

### Data Cleaning

* Removed currency symbols from the Price column.
* Converted prices into numerical format.

### Visualizations Created

#### 1. Rating Distribution Chart

Purpose:

* Understand how books are distributed across rating categories.

Insight:

* Ratings were spread across all categories, providing a balanced view of the dataset.

#### 2. Price Distribution Histogram

Purpose:

* Analyze the distribution of book prices.

Insight:

* Most books were priced within a relatively narrow range.

#### 3. Price vs Rating Boxplot

Purpose:

* Explore the relationship between book ratings and prices.

Insight:

* Higher ratings did not necessarily correspond to higher prices.

#### 4. Average Price by Rating Chart

Purpose:

* Compare average prices across rating categories.

Insight:

* Price differences existed across categories, but rating alone was not a strong predictor of price.

### Skills Gained

* Data visualization
* Storytelling with data
* Insight generation
* Analytical interpretation

## Outcome

Created multiple visualizations that enhanced understanding of the dataset and highlighted important trends.
